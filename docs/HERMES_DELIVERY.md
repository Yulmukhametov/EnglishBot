# Строгий порядок голосовых уроков в Hermes

Дополнение к уже установленному Hermes. Работает без инструмента `send_message` у модели.
Программа вызывает Telegram Bot API напрямую, используя существующий токен только локально.
Основная модель остаётся подключённой через ChatGPT/Codex. OpenAI audio API не используется.

## Установка на сервере

Войти в SSH, затем переключиться на того же пользователя, под которым работает Hermes:

```sh
su - hermes
```

Под пользователем `hermes` (не root):

```sh
git clone https://github.com/Yulmukhametov/EnglishBot.git /home/hermes/EnglishBot-delivery
bash /home/hermes/EnglishBot-delivery/deploy/install-hermes-delivery.sh
/home/hermes/.local/bin/hermes gateway restart
```

Выполняйте по очереди. При ошибке остановитесь и пришлите её без секретов. Если папка
уже существует, не удаляйте её; для обновления используйте `git -C /home/hermes/EnglishBot-delivery pull --ff-only`,
затем снова запустите установщик. Не клонируйте повторно поверх существующей папки.

Установщик использует `hermes pm environment` для отдельного окружения с Edge TTS и python-dotenv.
Python-окружение самого Hermes не изменяется. Skill появляется в текущем HERMES_HOME/skills,
по умолчанию `/home/hermes/.hermes/skills/english-lesson-delivery`.

Затем в Telegram отправьте:

> Используй skill english-lesson-delivery и его программу send-lesson для голосового урока.
> Моя фраза: Yesterday I go to work and buyed coffee.
> После успешного выполнения программы не дублируй текст или аудио обычным ответом.

Если агент не находит skill, начните новый чат `/new` и повторите запрос. Если terminal tool
отключён, включите его для Telegram через `hermes tools`. Общую конфигурацию прав/инструментов
менять автоматически не требуется. Установщик не меняет SOUL.md и не включает доступ для друзей.

## Русский голос и форматирование

Объяснение делится на русские и английские фрагменты по письменности слов.
Русские фрагменты озвучивает `ru-RU-DmitryNeural`, английские — `en-US-GuyNeural`.
Темп слегка замедлен (-5%). Фразы не переводятся и не заменяются фонетической транслитерацией.
Перед сменой языка добавляется пауза 0,2 секунды. Части собираются FFmpeg в одно голосовое.
Голосовые в чате остаются двумя отдельными сообщениями. Тембры русского и английского голосов различаются;
человеческая интонация на каждом примере не гарантирована и проверяется прослушиванием.
Много коротких переключений языка ухудшает естественность: skill рекомендует целые примеры и короткие предложения.

Поддерживается `**жирное выделение**`, преобразуемое в безопасный Telegram HTML.
Разметка удаляется перед синтезом; слова остаются теми же. Произвольный HTML экранируется.
Ошибки и исправления выделяет модель в тексте урока, программа не ищет грамматические ошибки самостоятельно.
Вторая расшифровка поддерживает выделение внутри общего спойлера.

Установщик добавляет `imageio-ffmpeg` только в отдельное окружение инструмента.

## Гарантии и ограничения

- Подготовлены оба MP3 до первой отправки. Telegram sendVoice поддерживает MP3.
- Затем идут четыре синхронных вызова: sendVoice -> sendMessage -> sendVoice -> sendMessage.
- Следующий вызов начинается только после успешного ответа Telegram с ожидаемым chat.id и message_id.
- Последняя расшифровка экранируется и скрывается через HTML tg-spoiler.
- Используется текст, из которого синтезировался голос; фонетические нормализации TTS возможны.
- На одну последовательность выдаётся request_id. Повтор завершённой последовательности не отправляет ничего заново.
- Сбой или потерянное подтверждение останавливают последовательность; автоматического повтора нет.
  При неоднозначном сетевом сбое часть сообщений может быть доставлена. Журнал содержит подтверждённые IDs;
  он не даёт гарантии exactly-once при потере ответа Telegram. Неполные попытки требуют ручного разбора.
- Один неблокирующий process lock предотвращает перемешивание двух уроков этого инструмента.
  При занятости вторая попытка возвращает ошибку до отправки. Уведомления других механизмов Hermes могут приходить отдельно.
- Подтверждение — это принятие сообщения Telegram, не прочтение/прослушивание пользователем.
  Клиент может загружать аудио медленнее текста даже при правильном порядке сообщений в истории.
- Только личный бот с ОДНИМ числовым TELEGRAM_ALLOWED_USERS. Для групп, нескольких пользователей,
  username-allowlist и TELEGRAM_ALLOW_ALL_USERS программа отказывает. Раздельное обучение друзей ещё не реализовано.
- Токен берётся из HERMES_HOME/.env либо окружения. Он не попадает в параметры команд и сообщения об ошибках.
- Журналы с хешами уроков и IDs находятся в HERMES_HOME/english-lesson-delivery-state.
  MP3 временные, удаляются после обработки. Исходный текст временного JSON-файла должен удалять вызвавший агент.
- Edge TTS отправляет текст внешнему сервису синтеза. В коде нет OpenAI API-расходов для озвучки,
  но доступность/лимиты Edge, качество голоса и работу с Telegram нужно проверить на VPS.
- Навык отвечает за доставку. Проверка произношения, полнота учебного курса и база прогресса им не добавляются.

Для теста проверьте порядок в истории чата, два отдельных voice bubble, текст после каждого,
спойлер только у второго текста, отсутствие дублированного финального ответа.
Если появляются лишние голосовые/сообщения, проверьте, не включён ли другой механизм автоматической
озвучки и не добавляет ли агент повторный ответ после работы инструмента.

## Автотесты

`pytest -q tests/test_ordered_delivery.py` проверяет порядок, остановку на каждом из четырёх шагов,
повтор после завершения/сбоя, блокировку параллельной доставки, экранирование спойлера,
валидацию chat.id и ограничение получателя. Telegram и Edge TTS подменены; реальных отправок нет.
