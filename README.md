# EnglishBot — личный AI-наставник в Telegram

Первая версия на **OpenAI API**. Запускается на домашнем Windows-компьютере.
Обучать свою модель не нужно. Подписка ChatGPT и API имеют отдельный учёт оплаты.

## Что работает в коде

- Текст и голосовые Telegram в одном диалоге.
- Исходное аудио отправляется аудиомодели: расшифровка с сохранением ошибок и экспериментальные наблюдения о произношении.
- Текстовая модель разбирает грамматику и лексику, продолжает разговор, ведёт учебные заметки.
- Порядок ответа: **голосовой разбор → его текст → голосовое продолжение на английском → текст под спойлером**.
- Если разбирать нечего, первый голосовой ответ пропускается. При сбое озвучивания приходит текст, английский также скрыт.
- Текст расшифровки берётся из результата генерации соответствующего голоса; точность соответствия проверяется вручную.
- Знакомство и предварительная диагностика через несколько сообщений, адаптивный план, домашние задания, стили общения.
- SQLite хранит профиль, последние сообщения, учебные наблюдения, словарь с датами повторения.
- Только один разрешённый пользователь и только личный чат. Ограничение длины сообщений и дневного числа обращений.

**Это первая проверяемая версия, а не подтверждённая система оценки произношения или сертифицированный CEFR-тест.**
Нельзя по одной расшифровке оценить звуки; аудиомодель действительно получает запись, но её замечания всё равно могут ошибаться.
Нет автоматических напоминаний, готового курса с валидированными тестами и автоматической выдачи сертификатов.
Словарь пока хранит выражения, а примеры и упражнения создаются по запросу. Повторения запускаются через `/review`.

## Запуск на Windows 11

Нужны Python **3.11 или новее**, FFmpeg, доступ к Telegram и OpenAI API в вашем регионе и оплаченный API-аккаунт с доступными моделями.
Эта инструкция не устанавливает обходы региональных ограничений. Если OpenAI недоступен, сначала нужно выбрать доступного провайдера.

1. Скачайте репозиторий: **Code → Download ZIP**, распакуйте архив. Либо используйте Git.
2. Установите Python с [python.org](https://www.python.org/downloads/). В установщике включите добавление Python в PATH.
3. Установите FFmpeg. В PowerShell можно выполнить:

   ```powershell
   winget install --id Gyan.FFmpeg -e
   ```

   Откройте новое окно PowerShell и проверьте `ffmpeg -version`.
   Если FFmpeg установлен вручную, путь к `ffmpeg.exe` можно задать в `.env`.
4. Откройте PowerShell в папке проекта и выполните:

   ```powershell
   py -3 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -e .
   Copy-Item .env.example .env
   notepad .env
   ```

5. Заполните `.env`:
   - `TELEGRAM_BOT_TOKEN` — создайте бота у **@BotFather** в Telegram командой `/newbot`.
   - `OPENAI_API_KEY` — ключ из [API Platform](https://platform.openai.com/api-keys), НЕ пароль ChatGPT.
   - `OWNER_ID` — ваш числовой Telegram ID, например его можно узнать у **@userinfobot**. Это не username и не ID бота.
   - Остальные настройки можно оставить. Для `FFMPEG_PATH` в Windows используйте прямые слеши, например `C:/Tools/ffmpeg/bin/ffmpeg.exe`.

   **Не отправляйте ключи в чат, не добавляйте `.env` в GitHub и не публикуйте базу данных.**
6. Запустите:

   ```powershell
   .\.venv\Scripts\python.exe -m englishbot
   ```

7. Откройте своего бота в Telegram и отправьте `/start`.
   Для остановки — `Ctrl+C`. Для повторного запуска можно открыть `start.bat`.

Компьютер должен быть включён, без сна, с интернетом; окно программы должно оставаться открытым.
Входящие сообщения Telegram хранятся ограниченное время (обычно до 24 часов), поэтому сообщения за выключенные выходные могут потеряться.
Публичный IP, открытие портов и отдельный сервер не нужны: используется long polling.
Одновременно запускайте только один экземпляр бота с этим токеном.

## Команды

| Команда | Действие |
|---|---|
| `/start`, `/help` | Знакомство, описание и справка |
| `/goal Путешествия, 20 минут в день` | Сохранить цель; после изменения обновите план |
| `/style friendly` | Дружелюбный наставник |
| `/style strict` | Строгий, уважительный преподаватель |
| `/style casual` | Неформальное общение |
| `/plan` | Создать или обновить план; результат также доступен в `/progress` |
| `/homework` | Подобрать задание; работу отправляйте обычным сообщением или после команды |
| `/progress` | Показать уровень, план, задание, учебные наблюдения |
| `/word take a break` | Добавить слово или выражение |
| `/words` | Показать до 200 слов |
| `/review` | Упражнение со словом, которому подошла дата повторения |
| `/usage` | Число успешных API-вызовов за текущий день UTC |
| `/forget`, затем `/forget confirm` | Удалить локальные учебные данные |

Кнопки повторения — самооценка, а не автоматическая проверка знания. Ответ на упражнение проверяет AI при отправке.
Интервалы: 1, 3, 7, 14, 30, 60 дней; после ошибки — через 10 минут.
Начальный уровень предварительный. Говорение, письмо и понимание на слух проверяются отдельно в процессе обучения.

## Модели и стоимость

По умолчанию `TEXT_MODEL=gpt-5-mini`, `AUDIO_MODEL=gpt-audio-1.5`, `VOICE=alloy`.
Названия вынесены в `.env`: доступность нужно проверить в своём API-аккаунте.
Аудиомодель используется как для анализа записи, так и для озвучивания через Chat Completions;
отдельный специализированный сервис произношения не подключён.

Одно голосовое с разбором обычно вызывает **4 запроса**: анализ аудио, урок, озвучивание разбора, озвучивание продолжения.
Текстовое с разбором — 3 запроса. Если нет разбора, на один запрос меньше.
Вызовы анализа и озвучивания аудио используют аудиотокены; расходы не равны цене обычной текстовой переписки.

`DAILY_TURN_LIMIT=40` ограничивает число учебных обращений, **не денежный расход**.
Неудачные попытки также занимают обращение; SDK может повторить сетевой запрос один раз.
Счётчик обновляется в 00:00 UTC. `/plan`, `/homework`, `/review` тоже расходуют обращения.
Входящие слишком длинные голосовые и текст отклоняются до вызова AI.
Для финансового контроля используйте кабинет [OpenAI Usage](https://platform.openai.com/usage),
небольшой начальный баланс без автоматического пополнения и уведомления о расходах.
Бюджет проекта у провайдера может быть уведомлением, а не жёстким ограничением.

## Данные и ограничения

`data/mentor.sqlite3` — база на компьютере. Последние 40 сообщений и накопленные AI-заметки используются для памяти;
на каждый запрос передаются последние 12 сообщений и профиль. Весь архив разговора модель не помнит дословно.
Заметки и оценка уровня создаются моделью и могут ошибаться. Словарь добавляется явно через `/word`.
Аудио временно хранится в системной временной папке и удаляется при штатном завершении обработки;
при аварийном отключении остатки могут потребовать очистки временной папки Windows.
Данные передаются Telegram и OpenAI согласно их политикам; локальное удаление не удаляет сообщения из этих сервисов.
`/forget confirm` логически удаляет учебные записи из SQLite, но не является гарантированным стиранием носителя или резервных копий.
Счётчики обращений и техническая статистика API сохраняются; статистика не содержит текстов сообщений.
Файл базы не зашифрован приложением: используйте защищённую учётную запись Windows и защищённые резервные копии.
Синтезированный голос обозначен как AI в `/start` и `/help`.

## Проверки

Пошаговый план ручных испытаний: [docs/TESTING.md](docs/TESTING.md).

```powershell
.\.venv\Scripts\python.exe -m pip install -e '.[dev]'
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
```

Автотесты не используют реальные ключи и не отправляют сообщения в Telegram/OpenAI.
Проверки преобразования аудио используют настоящий FFmpeg; если его нет, соответствующие тесты пропускаются.
Они проверяют программу, а не качество AI. Голос, произношение и педагогический результат требуют живого теста.

## Структура

- `englishbot/bot.py` — Telegram, команды и порядок ответов.
- `englishbot/ai.py` — OpenAI: исходное аудио, урок, голос.
- `englishbot/prompts.py` — правила преподавателя.
- `englishbot/store.py` — SQLite и интервалы повторения.
- `tests/` — проверки без внешних запросов.
